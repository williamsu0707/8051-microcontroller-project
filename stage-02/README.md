# Stage 02 — Seven-Segment Display

This lab used two switches and 8051 interrupts to control a seven-segment display. One switch counts upward from 0 to 9, and the other counts downward from 9 to 0.

- [Lab report (PDF)](seven-segment.pdf)

The report includes circuit photos, a flowchart, code listings, and troubleshooting notes. A separate assembly source file was not provided for this stage.
